# Звуки BibleLoop

Три оригинальных синтезированных PCM WAV: правильный ответ, ошибка и завершение урока. Создаются скриптом `python3 scripts/generate-sounds.py`, сторонних сэмплов нет.

Проигрываются только после действий пользователя через SoundProvider. Не зацикливаются. Настройка звука сохраняется отдельно от учебного прогресса. При отключении звука или уходе приложения в фон воспроизведение останавливается. На телефоне учитывается беззвучный режим.
